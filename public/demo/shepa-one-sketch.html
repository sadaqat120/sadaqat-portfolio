Talking within 60 seconds, and a rating ask only after a good conversation

A clickable sketch of two changes: the first minute for a new user, and when to ask for an App Store rating. Made by Sadaqat Rasool for our call. No code from your app was used; the screens are mock-ups.

What I saw

No rating score yet

The App Store page (US and MX) says the app "hasn't received enough ratings or reviews to display an overview". For a social app, that's often where people decide not to install.

Why it matters

Empty rooms lose users

In a language-exchange app, a new user who waits and sees nobody usually leaves. Your AI Talk (added in 1.2.28) can fill that gap so nobody waits.

The idea

Ask happy users only

Ask for a rating right after a conversation the user says was good. Unhappy users get a private feedback form instead. That way the ratings that come in reflect your best moments.

When the rating prompt is allowed to show

1
The user tapped Great after the conversation.
2
The conversation lasted 3 minutes or more (both sides stayed).
3
It is not the very first session (they have come back at least once).
4
We haven't asked in the last 120 days. Apple shows the system prompt at most 3 times a year anyway, so each ask has to count.
5
Never after a bad call, a report or a connection problem.
// iOS (Swift): after the "How was it?" answer
func afterSession(_ s: Session, mood: Mood) {
  guard mood == .great,
        s.duration >= 180,
        user.sessionCount >= 2,
        daysSince(user.lastRatingAsk) >= 120,
        !s.hadReport, !s.hadConnectionIssue else {
    if mood == .notGood { showPrivateFeedback(s) }
    return
  }
  user.lastRatingAsk = .now
  if let scene = activeWindowScene {
    SKStoreReviewController.requestReview(in: scene) // or AppStore.requestReview
  }
}
// Android: the same rule, then the Play In-App Review API.

The first minute

  • Only 2 questions before the first call: what you speak, and what you want to practise.
  • Match for up to 20 seconds. If nobody fits, offer AI Talk immediately, and notify them when a person comes online.
  • A starter topic on screen, so nobody freezes.
  • Profile, photo and follows come after the first good conversation, not before.

Three small things I noticed on the App Store page

  • The description has a Chinese full-width comma ("，") and reads like a translation. One clean paragraph with the 3 main features would convert better.
  • The in-app purchase list shows "vip_month $4.99" but also "month $299.00" and "vip_month $299.00". If $299 isn't meant to be monthly, it's worth checking in App Store Connect.
  • The age rating is 4+ while the app has video calls and chat with strangers. It's worth checking this against Apple's rules for user-generated content (report and block in the call screen).
